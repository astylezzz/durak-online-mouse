# Мышиный дурак 🐭

Карточный клуб для двоих: мышь-мальчик, мышь-девочка, неоновые ушки и подкидной дурак на 36 карт. Адаптирован для телефона и компьютера. Регистрация не нужна.

## Как играть

1. Оба игрока открывают один сайт, вводят ник и выбирают мышонка.
2. Оба вводят **одинаковый секретный пароль** (от 6 символов). Первый открывает комнату, второй подключается к нему.
3. Нажмите карту, чтобы атаковать. При защите выберите непокрытую карту на столе, затем свою. Можно взять, подкинуть или отправить покрытые карты в отбой. После партии доступен реванш.

Комната рассчитана ровно на двоих. Не закрывайте вкладки во время партии. Выбор персонажа не ограничен полом другого игрока.

## Разработка

Node.js 22+ и npm. В облачной задаче используйте существующий checkout `/workspace/durak-online-mouse`: отдельный worktree не нужен.

```sh
npm ci
npm run dev
```

```sh
npm test          # правила и 100 симуляций партий
npm run build    # статическая сборка в dist/
npm run preview  # проверка production-сборки
```

Браузерная проверка с настоящим WebRTC и локальной сигнализацией (включает полную партию, реванш, третьего игрока, мобильный экран):

```sh
npx playwright install chromium
npx playwright test
# Если Chromium уже установлен в системе:
CHROMIUM_PATH=/usr/bin/chromium npx playwright test
```

## GitHub Pages

Workflow `.github/workflows/deploy.yml` проверяет правила, собирает сайт и публикует `dist` при push в `main`. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. После включения запустите **Actions → Deploy to GitHub Pages → Run workflow**, если push был раньше включения Pages. URL опубликованного сайта появится в успешном job `deploy`.

`base: './'` позволяет размещать сайт в `/durak-online-mouse/`. Секреты, база данных и собственный сервер для стандартного запуска не нужны.

## Соединение и ограничения

Сайт статический. Для поиска друг друга используется публичный PeerJS Cloud (домен `0.peerjs.com` и его инфраструктура), затем браузеры передают ходы через WebRTC DataChannel. Общий пароль хешируется SHA-256; исходный пароль не отправляется сервису сигнализации. Это ключ комнаты, а не система аккаунтов: используйте длинный уникальный пароль, который сложно угадать. Ник передаётся второму игроку.

Создатель комнаты хранит полное состояние колоды и проверяет ходы обоих игроков; сопернику передаются только его карты и число чужих. Это дружеская игра с доверием к создателю, без защиты от модифицированного клиента. После перезагрузки создателя партия теряется. Второй игрок может вернуться с тем же паролем из той же вкладки (sessionStorage хранит идентификатор сессии).

Прямое соединение может не работать за строгим NAT, корпоративным firewall или VPN. Собственный TURN-сервер не настроен. При проблемах попробуйте другую сеть. Доступность публичной сигнализации — внешняя зависимость. Google Fonts используется только для шрифта, при недоступности работает системный шрифт.
